# QQ 音乐保守版：只清理独立广告 SDK 接口（2026-10-17）

用户希望减少反复切阶段、抓包和查日志的负担，授权尝试稳定优先的保守处理。本次使用现有捕获完成离线分析，不要求再进行一轮诊断实验。

这是保守版的历史记录。用户随后反馈界面没有明显区别并要求更彻底地处理，当前同一安装地址已更新为 [扩展净化版](qqmusic-enhanced-ad-filter.md)，新增的深度净化默认开启；本页关于“没有 Script”和仅一个 MITM 主机的描述只适用于此前保守版。

## 实际处理范围

恢复原 [QQ 音乐去广告安装地址](https://raw.githubusercontent.com/ccyykk666/Loon-Plugin/main/plugins/qqmusic/qqmusic_ad.lpx)，实现改为一条 Loon 原生 JQ Rewrite：

| 项目 | 规则 |
| --- | --- |
| 主机 | `music.y.qq.com` |
| 路径 | `/maproxy/getInfo`，允许查询参数 |
| 请求方法 | POST |
| 响应条件 | HTTP 200，Content-Type 为 application/json |
| 正文条件 | 顶层对象、`ret == 0`、`rpt_msg_pos_ad_info` 为数组 |
| 修改 | 将 `rpt_msg_pos_ad_info` 设为空数组 |
| 保留 | 状态、广告 SDK 配置、Cookie、序列、时间及其他字段的原值 |

插件没有 Script、远程 JS、Mock、Reject、阶段参数或压缩库；仅为 `music.y.qq.com` 启用 MITM。它仍依赖 HTTPS 解密及原生 JSON 处理，不能称为完全无开销或保证所有设备一直正常。

不会匹配 `u6.y.qq.com`、`szu6.y.qq.com`、`shu6.y.qq.com` 或其他主机的 `musics.fcg`，不处理聚合推荐、登录、歌曲信息、会员状态。旧 `qqmusic_ad_filter.js` 继续保留为空放行兼容文件，没有恢复旧 JS。

## 抓包依据

复核现有 17 份已提供的捕获，目标路径共 254 条请求，均为 POST、HTTP 200、application/json 响应，原来没有脚本或正文修改标记，并均记录正文完整完成。

该接口的请求包含 `msg_ad_req_info`、`ad_user_info` 等广告 SDK 信息；响应的广告位置列表为 `rpt_msg_pos_ad_info`，内部广告项包括 `rpt_msg_ad_info`、广告主、素材、点击及展示配置。已观察到耳机活动、歌曲加热推广及电商推广等广告内容，因此并非仅根据 `getInfo` 路径名称猜用途。接口不承载音乐推荐列表或登录结果。

254 条响应顶层 `ret` 均为 0：100 条原本返回空广告列表，154 条返回非空列表。这为本次保留其他原字段、只清空列表提供了直接的服务器结构依据。它仍不是启用规则后的真机界面验证，不能从离线结果保证某个截图组件一定消失。

采用响应原生 JQ 而非整接口拒绝，是为了保留动态返回的广告 SDK 配置和 Cookie 等内容，避免猜测一个固定空包是否被客户端接受。JQ 只在成功响应且结构符合时处理；非对象、错误状态、字段缺失或字段类型变化时返回原值。使用语法见 [Loon 原生 Rewrite 文档](https://nsloon.app/docs/Rewrite/rewrite_v2/#json)。

## 没有加入的目标

- `/maproxy/getPbCompressAd`：79 条记录为 Protobuf 广告响应，不将其错误地按 JSON 处理，也不猜测无广告二进制响应或引入新的 JS 解码器。
- 旧 `/tips/fcgi-bin/fcg_get_advert.fcg`：19 条已捕获响应的广告数组本来都为空；`3g_get_mymusic_topbanner.fcg` 的 8 条响应也已为空，不增加无收益的兼容规则。
- 崩溃、性能及广告统计上报：没有证据表明拦截这些请求能去掉截图上的广告，因此不添加泛化域名规则。
- 通用图片/CDN、推送、支付、登录和未知域名：不因名字或关键词相似而拦截。
- 首页会员福利、AI 提示、个人页会员卡、金币入口、更多页推广等此前涉及共用接口的内容：本版保留，不承诺整体页面净化。

此接口可能也参与主动观看广告的活动；广告列表清空可能使相应活动没有可播放广告。规则不改变会员权限、任务奖励或支付结果，也不伪造观看成功。

## 离线检查和使用方式

使用实际 jq 1.8.2 对本批 254 条目标响应回放，检查 154 条非空列表清空、100 条原空列表保持，其他字段深度相等；10 个错误/缺失/类型变化样本返回原值。对现有 17 份捕获共 10044 条请求复核，规则只命中这 254 条，6827 条 `musics.fcg` 请求全部排除；另检查相邻路径、伪装子域、方法、状态和 Content-Type 的匹配边界。没有用 JavaScript 模拟 JQ 来冒充执行验证，也没有将桌面 jq 回放说成 Loon 真机通过。

使用时关闭“QQ音乐网络诊断”和“QQ音乐单规则诊断”，更新并只启用“QQ音乐去广告”，重启一次 Loon 连接后正常使用即可。不需要再选阶段、打开抓包或提交日志。主配置若另行启用了同主机的旧脚本或 MITM，更新本插件不会自动删除它们。

本版的目标是减少独立 SDK 下发的广告，不是恢复旧的全量净化方案。没有承诺去除所有推广，也没有取得本版的真机效果或长期稳定性验证。
